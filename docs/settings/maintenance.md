# System Controls

Manage the device name, saved setup, firmware, and Home Assistant image connection. Open **System > System** on your [device setup page](/features/setup).

| Setting | What to do |
|---|---|
| [Device Name](/features/device-name) | Rename the panel and check its new network address. |
| [Backup](/features/backup) | Export a setup or import a saved configuration. |
| [Firmware](/features/firmware-updates) | Check for updates and choose automatic update behaviour. |
| [Home Assistant Settings](/features/home-assistant) | Check or change the image and artwork connection. |
| [Battery](/features/battery) | Enable readings on compatible panels with a battery add-on. |
| [Factory Reset](/features/backup#reset-the-display) | Clear configuration, optionally keeping network credentials. |

Export a backup before resetting or changing firmware versions. Device Name, Battery, and Factory Reset need supported hardware or firmware. To restart without changing settings, use the [Home Assistant Restart button](/features/restart).
