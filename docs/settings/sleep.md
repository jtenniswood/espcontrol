# Sleep & Schedule

Choose when the screen sleeps, what it shows, and how it wakes. Open **Screen > Sleep & Schedule** on your [device setup page](/features/setup).

| Setting | What to do |
|---|---|
| [Cover Art Screen Saver](/features/media-cover-art) | Show artwork from a playing media player. |
| [Screensaver](/features/screensaver) | Sleep after inactivity or when a presence sensor clears. |
| [Night Schedule](/features/screen-schedule) | Set overnight behaviour using hours or a separate sensor. |
| [Pin Protection](/features/screensaver#pin-protection-after-wake) | Require a PIN before using touchscreen controls after wake. |

Start with **Screensaver > Timer** and **Then > Display Off**. Add Night Schedule if you need different overnight behaviour. A time-based Night Schedule takes priority over presence wake and media cover art; touch or Home Assistant’s **Screen: Wake** button still works.
