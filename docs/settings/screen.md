# Screen Settings

Open your [device setup page](/features/setup) and choose **Screen**. Choose a section below, then open its setting guide.

## Appearance

[Appearance](/features/appearance) contains **Active Colour**, **Card Style**, **Theme**, **Idle**, and **Clock Bar**. Use it to change the look of your cards, show the top bar, or return home after inactivity.

## Display

[Display](/settings/display) contains **Backlight** and **Rotation**. Set a comfortable brightness and match the panel’s mounting orientation.

## Sleep & Schedule

[Sleep & Schedule](/settings/sleep) contains **Cover Art Screen Saver**, **Screensaver**, **Night Schedule**, and **Pin Protection**. Choose when the panel sleeps and what it shows while idle or overnight.

## Set Up Everyday Behaviour

1. Set **Display > Backlight > Manual** to a comfortable brightness.
2. Set **Sleep & Schedule > Screensaver > Timer**, choose a delay, and choose **Then > Display Off**, **Screen Dimmed**, **Clock**, or **Camera**.
3. If needed, set **Night Schedule > Time** and choose daytime/night boundaries and an overnight action.
4. Choose **Apply Configuration**. Test the delay, touch to wake, and check the night boundary.

**Idle** returns to the home page; **Screensaver** controls inactivity; **Night Schedule** controls overnight behaviour. Time-based Night Schedule takes priority over screensaver presence wake and media cover art. Touch and Home Assistant’s **Screen: Wake** button still work.

Set the correct timezone in **System > Preferences > Time** before using automatic brightness, theme, or schedules. Check [firmware](/settings/maintenance#firmware) and model support if an option is missing.
