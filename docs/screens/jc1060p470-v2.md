# 7-inch JC1060P470 new panel

The newer JC1060P470 panel revision is now documented on the combined [7-inch JC1060P470](/screens/jc1060p470) page.

Guition ships two 7-inch panels under the same JC1060P470 name. If the label on the back of the case shows `V2` in the SKU / material number, use this profile. Older units use the original JC1060P470 profile. Wrong profile → white screen with a vertical noise band; reflash the other profile.
