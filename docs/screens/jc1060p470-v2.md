# 7-inch JC1060P470 new panel

The newer JC1060P470 panel revision is now documented on the combined [7-inch JC1060P470](/screens/jc1060p470) page.

Guition ships two 7-inch panels under the same JC1060P470 name. Use this profile when the case is marked `V2`. V1 / original cases have no version marking at all—they do not say `V1`. If needed, disconnect the display from power and remove the back: a screen-board date code of `2622` or higher identifies V2, while an earlier code identifies V1. Wrong profile → white screen with a vertical noise band; reflash the other profile.
