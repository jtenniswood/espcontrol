# 7-inch JC1060P470 V3

This firmware is for JC1060P470 panels with **ESP32-P4 v3.1–v3.99 production silicon**. Confirm the chip revision from ESPHome logs or `esptool` before installing; the rear-case marking alone is not sufficient.

The V3 panel uses the same 1024x600 landscape layout and 15-card configuration as the other JC1060P470 revisions. Its firmware uses the production-silicon display initialization and the browser firmware-upload endpoint is disabled; use USB for first installation and native ESPHome OTA for later updates.

Initial testing on **ESP32-P4 v3.2** confirmed boot, a full-screen picture and backlight control in [issue #2442](https://github.com/jtenniswood/espcontrol/issues/2442#issuecomment-6726398321). Touch, sleep/wake, native OTA and longer-term stability still need confirmation. This profile retains the V2 panel settings and uses the production-silicon display driver.

WebInstall becomes available after the first release containing this profile. Until then, build this branch through ESPHome.

## Install

Connect the display to your computer with a USB-C data cable, then install.

## ESPHome Manual Setup

```yaml
substitutions:
  name: "kitchen-screen"
  friendly_name: "Kitchen Screen"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

packages:
  setup:
    url: https://github.com/jtenniswood/espcontrol/
    file: devices/guition-esp32-p4-jc1060p470-v3/packages.yaml
    refresh: 1sec
```

## Manual USB fallback

If the browser installer cannot communicate with the panel, install the release image manually:

1. Open the [latest EspControl release](https://github.com/jtenniswood/espcontrol/releases) and download `guition-esp32-p4-jc1060p470-v3.factory.bin` from its **Assets**. Do not use the OTA image, a recovery image, or the source archive.
2. Confirm the chip is ESP32-P4 v3.1–v3.99 production silicon. Put the panel into download mode using its **BOOT/download** control: unplug it, hold BOOT while reconnecting the P4 USB programming cable, then release BOOT when the serial port appears.
3. Flash the downloaded **merged factory image** to the P4 serial port at address `0x0` with [esptool](https://docs.espressif.com/projects/esptool/en/latest/esp32p4/esptool/basic-commands.html), for example:

   ```bash
   esptool --chip esp32p4 --port YOUR_SERIAL_PORT write-flash 0x0 guition-esp32-p4-jc1060p470-v3.factory.bin
   ```

4. Reset or power-cycle the panel after the write completes. The first boot may take up to 90 seconds to create the `EspControl_XXXX` setup Wi-Fi network, where `XXXX` is the last four characters of the P4 MAC address.
5. Join that network and open `http://192.168.4.1` to enter Wi-Fi details, then complete Home Assistant pairing.

This is browser **USB installation**; it is separate from browser OTA. V3 deliberately rejects browser firmware uploads with HTTP 403. Once the panel is online, use native ESPHome OTA for later updates. If the hosted editor is blank or does not save settings, use the [embedded-editor workaround](/getting-started/troubleshooting#web-configuration-changes-won-t-save) with `?espcontrol_fallback=1`.

If upgrading from an earlier experimental V3 test build, export **System > Backup** first. USB flashing may replace the partition layout and erase stored configuration; restore the backup after Wi-Fi and Home Assistant are working.
