# 4.3-inch Sunton 8048S043

The **Sunton ESP32-8048S043** is a 4.3-inch landscape touchscreen powered by an **ESP32-S3** with 16 MB flash and 8 MB PSRAM. It has an 800×480 display with a GT911 capacitive touch panel and room for **12 cards** on the home screen.

The screen starts in its native landscape orientation. You can rotate it to portrait in the display settings, where the grid becomes 3 columns × 4 rows.

## Card Grid

<!--@include: ../generated/screens/8048s043-grid.md-->

This screen supports two shared image cards across the home page and subpages, such as one [Camera Card](/card-types/cameras) alongside one Media Cover Art card. Camera cards show still snapshots from `camera.*` or `image.*` entities. The Camera screensaver is supported; live video remains unavailable on this ESP32-S3 model.

For a full walkthrough including WiFi setup and Home Assistant pairing, see the [Install guide](/getting-started/install).

::: tip After flashing or OTA update
This panel uses a parallel RGB display with octal PSRAM, which requires a brief hardware reset after flashing or OTA updates. The firmware handles this automatically with a short deep-sleep cycle — the display may flicker once before coming back up normally.
:::

## ESPHome Manual Setup

If you use ESPHome and prefer to compile firmware yourself:

```yaml
substitutions:
  name: "hallway-screen"
  friendly_name: "Hallway Screen"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

packages:
  setup:
    url: https://github.com/jtenniswood/espcontrol/
    file: devices/sunton-esp32-s3-8048s043/packages.yaml
    refresh: 1sec
```
