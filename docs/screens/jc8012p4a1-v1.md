# 10.1-inch JC8012P4A1 V1

This is the **original panel** firmware for rear-case markings **`2627` or lower**.

::: warning Check the chip revision first
If ESPHome logs or `esptool` reports **ESP32-P4 v3.x production silicon**, use the [V3 page](/screens/jc8012p4a1-v3) regardless of the case date. Case dates are only a fallback when V3 silicon is not present.
:::

## Install

Connect the display to your computer with a USB-C data cable, then install.

## ESPHome Manual Setup

```yaml
substitutions:
  name: "kitchen-screen"
  friendly_name: "Kitchen Screen"

wifi:
  ssid: !secret wifi_ssid
  password: !secret wifi_password

packages:
  setup:
    url: https://github.com/jtenniswood/espcontrol/
    file: devices/guition-esp32-p4-jc8012p4a1/packages.yaml
    refresh: 1sec
```
